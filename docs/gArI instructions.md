**Set Up**  
in gari brain folder open cmd  
run: pip install -r requirements.txt

**In Game**  
/gari spawn [username]  
repeat for as many agents as you want (have to have unique usernames)  

### To Train
**In CMD**  
python train.py --agents [username1],[username2],... --timesteps [int (the higher the better)]  

### To Run  
**In Game**  
/gari spawn HIGHJACK299  
has to be HIGHJACK299  

**In gArI brain folder**  
double click RUN.bat **DO NOT CLICK RUN_AGENT.bat**
